Just a chess engine that I made with my free time some while ago. Made in C++ and it dosen't requires any dependencies. ELO rating is about 1200-1400.

Building from source:

In Windows:
1. Open CMD
2. Navigate to the same folder where Main.cpp file is.
3. Run: g++ -O3 main.cpp -o main
4. Now, run: main

The chess engine will play with itself.
